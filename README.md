# Kaspi-style Demo App

Демонстрационный интерфейс мобильного приложения на React + Vite. Все персональные данные вымышлены; макет удостоверения явно помечен DEMO и не является документом.

## Запуск
```bash
npm install
npm run dev
```
Откройте адрес Vite в браузере. Для production:
```bash
npm run build
npm run preview
```

## Возможности
- Главная, Госуслуги, документ DEMO и реквизиты.
- SPA-навигация без перезагрузки.
- Копирование реквизитов в буфер обмена.
- Поиск и переключение вкладок/категорий.
- Демонстрационные модальные окна.
- Последний экран сохраняется в LocalStorage.


Дополнительно: загрузка нескольких изображений и PDF на экране удостоверения, просмотр в увеличенном/развёрнутом окне. Файлы хранятся только в памяти текущей сессии браузера.
